Nick's Workout Tracker - Installable Phone App

This package is a Progressive Web App (PWA). It can be installed on Android through Chrome after it is opened from a web address.

IMPORTANT:
Opening index.html directly from your phone's Downloads folder may work for viewing, but it usually will NOT trigger true Add to Home Screen install behavior because PWAs need to be served from a web address.

Easiest ways to use it:
1. Upload the entire workout_pwa folder to any simple web host, Google Drive web host alternative, GitHub Pages, Netlify, Vercel, or your company/personal web space.
2. Open the web link in Chrome on your Android phone.
3. Tap the three-dot menu.
4. Tap Install app or Add to Home screen.
5. The app will appear on your phone like a normal app.

Your workout history is stored locally on that phone/browser. If browser storage is cleared, the history can be lost.
